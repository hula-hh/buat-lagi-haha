URL dan kunci disimpan di browser ini. Jangan isi kunci admin di perangkat publik. Untuk penggunaan produksi, ganti admin key browser dengan autentikasi admin yang sesungguhnya.

Panduan Setup

Langkah awal sebelum aplikasi digunakan.

1. Buat Google SheetBuka Extensions → Apps Script.
2. Pasang Code.gsSalin file apps-script/Code.gs, lalu jalankan setupYusen().
3. Atur ADMIN_KEYProject Settings → Script Properties.
4. Deploy Web AppExecute as Me, lalu salin URL /exec.

Lihat README.md untuk panduan lengkap dan catatan keamanan.
